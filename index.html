Inverter Control

FREELANCE / WITH POWER, FOR RIFT VALLEY

A web-based system for monitoring and controlling an ESP32-connected inverter, connecting the operator interface to the device through a Node.js backend and MQTT.

Project scope
Web interface, backend integration & IoT communication
What it brings together
Live status over WebSocket, tracked control commands, role-based access, and PostgreSQL-backed command and audit logs.
Node.jsPostgreSQLMQTTESP32WebSocket
Explore case study
Problem
Operators need a web interface to observe device status and follow the outcome of remote commands.
Architecture
Browser → Node.js / Express → PostgreSQL + MQTT → ESP32; WebSocket returns live updates.
My contribution
Built the inverter backend with MQTT over TLS, HttpOnly authentication cookies, role-based access, audit logs and command acknowledgement validation.
Engineering challenge
Tracking command acknowledgements, timeouts and offline devices while separating operator and administrator access.
What was built
An implemented control workflow with command history, device status and audit logging.

Pizza Go

GRADUATION PROJECT / FULL-STACK & IoT

A smart pizza-ordering experience connected to an automated preparation system. It connects customer ordering and payment with a queue of instructions for ESP32-controlled hardware.

Project scope
Integrated web, backend & hardware project
What it brings together
Pizza customization, Stripe test payments, PostgreSQL order storage, MQTT communication, machine heartbeat monitoring, and order tracking.
HTMLCSSJavaScriptNode.jsPostgreSQLStripeMQTTESP32
Explore case study
Problem
Online ordering must connect to the sequence of operations in an automated preparation machine.
Architecture
Web client → Express / PostgreSQL → order queue → MQTT / ESP32; Stripe handles test payments.
My contribution
Designed the system and programmed two ESP32 controllers for linear actuators, stepper motors, relays, a conveyor belt and a sauce pump, integrated with the backend.
Engineering challenge
Coordinated production with a finite-state machine and heartbeat monitoring; debugged hardware, firmware and communication, and tested the complete system.
What was built
An integrated graduation-project workflow from pizza customization to preparation-status tracking.
